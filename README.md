# IndividEdu login and registration prototype

## Run locally
1. Download and extract `individedu_source.zip`.
2. Open `index.html` in a modern web browser.

## Included
- Admin, Student, and Teacher login tabs
- Student sign-up fields: student name, class, subjects, school, father name/occupation/contact, mother name/occupation/contact
- Teacher sign-up fields: name, school, subjects, previous teaching experience in years, contact number
- Responsive layout and basic required-field validation

## Important
This is a front-end prototype only. It does not store registration data or authenticate users. Before public deployment, connect a secure backend/database and authentication provider, enforce role-based access, protect student/parent data, and create admin accounts securely. Do not use a browser-only form as the production login system.
